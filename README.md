## class-schedule-backend-node

这是 [class-schedule](https://github.com/liulyxandy-codemao/class-schedule) 的 Node.js 版本后端。

### 适用版本

- class-schedule v2.2.0 及以上版本

> [!IMPORTANT]  
> 此仓库使用的是 [API v2](https://class-schedule.apifox.cn) 版本。

### 推荐运行环境

- Node.js v20+
- SQLite v3
